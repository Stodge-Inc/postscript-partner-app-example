# Postscript partner app example

A minimal OAuth app for the Postscript 2.0 API. To create a partner account, a test store and an app, follow the [Partner quickstart](https://developers.pscrpt.com/docs/getting-started/partners).

## Run it locally

Requires Node 20.6+.

1. Copy `.env.example` to `.env` and fill in the client ID and secret.
2. Run `npm install && npm start`.
3. Open http://localhost:3000 and select **Connect**.
4. Approve the install on your test store.
